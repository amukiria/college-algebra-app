# College Algebra Learning App

An interactive learning platform for College Algebra students. The app provides structured lessons, practice exercises, quizzes, and exam practice across all major College Algebra topics.

Live: [college-algebra-app.vercel.app](https://college-algebra-app.vercel.app/)

---

## Features

- Structured **Learn** and **Practice** sections for each topic
- **Quiz** and **Exam Practice** modes for assessment
- **Graphing Assignment** for applied work
- User authentication via Clerk — sign in to track progress
- Clean, responsive UI built with Tailwind CSS
