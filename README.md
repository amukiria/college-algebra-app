# College Algebra Learning App

A gamified and interactive learning platform for College Algebra students. This app combines engaging visualizations, dynamic problem generation, and lessons to make learning algebra effective and enjoyable.

---

## Features
### Core Functionalities
1. Dynamic Question Generation:
   - Generate algebra problems for topics like sets, polynomials, quadratic equations, and more.
   - Difficulty levels tailored to student progress.
2. Interactive Visualizations:
   - Use dynamic Venn diagrams and polynomial graphs to visualize concepts.
3. Step-by-Step Solutions:
   - Provide detailed explanations for solving problems interactively.
4. Gamified Learning:
   - Achievements, progress tracking, and badges motivate continuous practice.

### Course Coverage
- Sets and their operations.
- Polynomials and algebraic expressions.
- Quadratic equations and solutions.
- Progressions and more.

## Tech Stack
### Frontend
- Next.js: Framework for building scalable and interactive web apps.
- Tailwind CSS: For consistent and responsive styling.
- D3.js: For dynamic visualizations like Venn diagrams and polynomial graphs.

### Backend
- Vercel: Handles serverless deployment and builds.
- Wolfram Alpha API: Provides dynamic problem generation and solutions.

### Database
- MongoDB Atlas: Stores user progress, achievements, and problem sets.
